# Uživatelská příručka MacContestLogger

Stránky níže sledují pořadí aplikace: první kroky, okna, provoz, síť, data.
Názvy oken a položky menu jsou uvedené tak, jak se zobrazují v uživatelském rozhraní aplikace.
Anglická verze příručky je v [../README.md](../README.md).

Celá příručka je k dispozici také jako jedno PDF (obsah, záložky, čísla stran) a jako jeden samostatný HTML
soubor (všechny obrázky uvnitř; otevřete ho v prohlížeči, případně upravte a vytiskněte nebo exportujte do PDF): každé vydání
má přiložené `MacContestLogger-manual.pdf` a `MacContestLogger-manual.html` a **Nápověda → Stáhnout nejnovější
PDF manuál…** nebo **Stáhnout nejnovější HTML manuál…** v aplikaci stáhne ten nejnovější.

Snímky obrazovky ukazují české uživatelské rozhraní aplikace, takže odpovídají této české verzi příručky. Pořízené byly
v dřívější javové verzi aplikace; současná nativní verze pro macOS vypadá trochu jinak, ale ovládací prvky a jejich význam jsou stejné.
